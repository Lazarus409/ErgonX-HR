## Brand & Style

This design system establishes an institutional-grade, highly structured visual environment designed for complex enterprise resource planning, corporate governance, multi-entity accounting, and statutory oversight. It prioritizes clarity over ornamentation, structural density over loose decorative padding, and rapid executive scanning over casual consumption.

### Target Audience
C-suite finance executives, multi-entity controllers, enterprise auditors, operational directors, and institutional administrators requiring real-time, error-free oversight and mass-transaction processing.

### Emotional Response
- **Uncompromised Authority:** Grounded deep midnight foundations anchor the interface, conveying regulatory security, compliance, and institutional stability.
- **Architectural Clarity:** Strict line weights, neutral container elevations, and disciplined alignment eliminate ambiguity across data grids and complex financial workflows.
- **Controlled Precision:** Kinetic vibrant accents (vivid blues and subtle cyan highlights) direct visual focus purely toward critical actions, pending approvals, and systemic deviations.

### Design Movement
**Corporate Modernist Precision:** A rigorous intersection of contemporary Scandinavian utilitarianism and Swiss structural data layout. High-contrast typography paired with razor-sharp division lines, crisp white surfaces resting over slate-tinted canvases, and restrained, intentional kinetic gradients across primary milestones.

## Colors

The palette is engineered for cognitive endurance in data-dense financial environments. High-contrast midnight anchors define structural navigation and command shells, balanced against pure light workspaces and strict semantic governance indicators.

### Structural Anchors
- **Primary Shell (`#0B192C`):** The midnight bedrock applied to persistent left rail navigation, executive modal headers, and primary data contrast anchors.
- **Navigation Inactive Surface (`#0F172A`):** Deep slate-navy supporting sub-navigation groupings and nested navigation tiers.
- **Interactive Primary Accent (`#2563EB` / `#1D4ED8`):** Royal Blue reserved strictly for high-priority interactive states, key task triggers (`Create Journal`, `Save & Post`), active pagination dots, and focused form outlines.

### Work Surfaces & Borders
- **Application Canvas (`#F8FAFC`):** A cool-tinted off-white background mitigating eye fatigue during prolonged analytical sessions.
- **Card Surfaces (`#FFFFFF`):** High-opacity pure white panels creating distinct foreground separation.
- **Dividers & Structural Borders (`#E2E8F0`):** Consistent 1px neutral barriers separating ledger data cells, toolbar actions, and grouped modules.
- **Muted Borders (`#CBD5E1`):** Applied to active input boundaries and secondary interactive states.

### Semantic Status Spectrum
- **Success (`#059669` / `#ECFDF5`):** Approved, posted, reconciled, balanced journals.
- **Pending / Warning (`#D97706` / `#FFFBEB`):** Approval pending, variance detected, awaiting secondary signature.
- **Critical / Danger (`#DC2626` / `#FEF2F2`):** Overdue, validation failure, segregation-of-duties conflict, voided.
- **In-Progress / Informational (`#0284C7` / `#F0F9FF`):** Processing batch, draft state, open period.
- **Neutral / Draft (`#475569` / `#F1F5F9`):** Inactive entity, archived line items, not sent.

### Accent Gradients
- **Brand Horizon Accent:** Linear gradient (`135deg`, `#06B6D4` 0%, `#2563EB` 100%) reserved for global progress meters, logo mark highlights, and active rail micro-indicator notches.

## Typography

The typographic hierarchy couples **Hanken Grotesk** for architectural display headers with **Manrope** for dense, readable tabular forms and transactional interfaces.

### Tabular Numerals & Ledger Data
All monetary values, journal numbers, date ranges, and quantities must strictly leverage `font-feature-settings: "tnum" 1, "cv05" 1`. This aligns decimals and currency markers across nested table rows without drift.

### Type Roles
- **Display & Section Headers (`Hanken Grotesk`):** Assertive weights (`600`, `700`) communicate structural ownership of multi-entity submodules (e.g., Accounts Payable, General Ledger).
- **Body & Controls (`Manrope`):** Optimized for high legibility at 12px to 14px sizes. Modest ascender height provides vertical rhythm when rendering dense multi-line audit events.
- **Labels & Micro-Tags:** Small caps or uppercase letter-spacing applied only to 10px-11px status indicators to preserve instant executive classification.

## Layout & Spacing

The layout is grounded on an 8pt metric rhythm with 4pt micro-steps for compact data components. It enforces clear functional boundaries across complex workspaces.

### Global Grid Architecture
- **Desktop (>= 1280px):** Fixed-width navigation sidebar (`260px` expanded, `72px` icon-rail collapsed) docked to a dynamic fluid content viewport. The content zone utilizes a 12-column grid with `1.5rem` (24px) gutters and `1.5rem` outer canvas padding.
- **Tablet / Split Screen (768px - 1279px):** Sidebar converts into an overlay drawer. Workspace transitions to an 8-column layout with `1rem` gutters. Slide-out inspection panels (such as Bulk Actions or Audit Detail) overlay up to 420px of screen real estate.
- **Mobile PWA Shell (< 768px):** Single-column stack with `1rem` canvas margins. Persistent 56px top app bar housing institution contextual switcher, global search icon, and profile trigger; 64px bottom navigation bar pinned to viewport base for instant thumb access to core functional pipelines.

### Spacing Principles
- Metric cards and overview stats maintain `space-lg` internal cell padding with a `space-md` gap between metric rows.
- Data table cells enforce compact vertical rhythm: `0.625rem` (10px) vertical cell padding for dense table rows and `1rem` (16px) for standard records.

## Elevation & Depth

Visual hierarchy uses crisp architectural surfaces, 1px perimeter definition, and low-diffused structural drop shadows. Pure flat styling is avoided to keep floating panels and bulk flyouts visually distinct from foundational canvases.

### Surface Hierarchy Levels
- **Base Canvas (Level 0):** `#F8FAFC` slate canvas. No shadow.
- **Card & Data Panels (Level 1):** `#FFFFFF` surfaces with a 1px solid border (`#E2E8F0`) and an ambient, low-opacity drop shadow:
  `box-shadow: 0 1px 3px 0 rgba(15, 23, 42, 0.05), 0 1px 2px -1px rgba(15, 23, 42, 0.05);`
- **Flyout Drawers, Context Menus & Popovers (Level 2):** Elevated interactive components with strict edge borders and heightened atmospheric dispersion:
  `box-shadow: 0 10px 15px -3px rgba(15, 23, 42, 0.08), 0 4px 6px -4px rgba(15, 23, 42, 0.04);`
- **Executive Modals & Critical Overlays (Level 3):** Centered floating modals supported by a 40% `#0B192C` backdrop overlay blur (`backdrop-filter: blur(4px)`):
  `box-shadow: 0 20px 25px -5px rgba(15, 23, 42, 0.12), 0 8px 10px -6px rgba(15, 23, 42, 0.06);`

### Border Philosophy
Shadows never act alone. Every elevated surface must be bounded by a 1px `#E2E8F0` or `#CBD5E1` border to preserve razor-sharp distinction under low-contrast office monitor conditions.

## Shapes

The design system employs a soft, highly restrained corner radius scale (`roundedness: 1`). Rounding is intentionally kept minimal to maintain an executive, institutional appearance and avoid overly informal, consumer-like curves.

### Corner Token Application
- **Input Fields, Dropdowns & Standard Buttons:** `rounded` (`0.25rem` / 4px). Delivers crisp architectural boundaries that align cleanly with dense financial tables.
- **Metric Tiles, Data Cards & Modals:** `rounded-lg` (`0.5rem` / 8px). Softens large perimeter containers without sacrificing data space.
- **Status Badges, System Pills & Avatars:** Fully rounded or `rounded-full` (`9999px`) to create clear differentiation between actionable square inputs and passive categorical tags.

## Components

### Buttons & Interactive Controls
- **Primary:** Background `#0B192C` (Midnight) or `#2563EB` (Royal Blue) for conversion funnels. Text `#FFFFFF`, font weight 600, border radius `4px`, padding `8px 16px`. Active press effect reduces opacity to 90% without vertical shifts.
- **Secondary / Outline:** Background `#FFFFFF`, 1px border `#E2E8F0`, text `#1E293B`. Hover shifts border to `#CBD5E1` and background to `#F8FAFC`.
- **Destructive:** Border and text `#DC2626`, hover background `#FEF2F2`.

### Enterprise Status Badges & Audit Pills
- **Geometry:** Height 22px, `rounded-full`, horizontal padding `8px`, typography `label-sm`.
- **Visuals:** Light-tint container with saturated label text and an optional 6px circular dot indicator:
  - *Success (Approved/Posted):* `#ECFDF5` container, `#059669` text and dot.
  - *Pending (Under Review):* `#FFFBEB` container, `#D97706` text and dot.
  - *Danger (Overdue/Rejected):* `#FEF2F2` container, `#DC2626` text and dot.
  - *Draft / Neutral:* `#F1F5F9` container, `#475569` text and dot.

### Data Tables & Grid View
- **Header:** Background `#F8FAFC`, uppercase `label-md` tracking, 1px bottom border `#E2E8F0`, column sorting chevron indicator with 4px gap.
- **Row States:** Default `#FFFFFF`, hover `#F8FAFC` transition (150ms ease). Selected row adopts `#EFF6FF` background with `#2563EB` 2px left border indicator.
- **Tabular Data:** Right-aligned numerical values using tabular numerals; left-aligned contextual metadata.

### Form Inputs & High-Contrast Controls
- **Text & Select Inputs:** Height 36px, border 1px solid `#CBD5E1`, background `#FFFFFF`, border-radius 4px. Focus state: `#2563EB` border with `0 0 0 2px rgba(37, 99, 235, 0.15)`.
- **Checkboxes & Radios:** 16px square/circle, border 1.5px solid `#94A3B8`. Selected state renders `#2563EB` fill with centered white checkmark icon.

### Governed Empty States
- Consists of a 48px circle container (`#F1F5F9`) with a 24px slate icon (`#64748B`), followed by a 15px semibold title (`#0F172A`), a short 13px explainer (`#64748B`), and a direct actionable primary button.

### Drawer & Inspector Panels
- Positioned fixed to the right edge with a `420px` default width (expandable to `560px` for multi-stage workflows). Contains a sticky header with title, close trigger, scrollable internal content zone, and a fixed bottom utility bar for multi-item batch execution (`Bulk Actions`).

### Mobile PWA Shell
- **Top Navigation Bar:** Sticky 56px, background `#FFFFFF` with 1px border-bottom `#E2E8F0`. Displays active institution selector pill (`Rivermere Health`), compact search icon, notification badge counter, and profile avatar.
- **Bottom Ergonomic Navigation:** Sticky 64px, background `#FFFFFF` with top border `#E2E8F0`. 4 to 5 core navigation items featuring an active state highlighted by a 2px `#2563EB` top edge indicator and saturated icon fill.
