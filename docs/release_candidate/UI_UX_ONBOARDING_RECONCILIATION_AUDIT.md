## Guardrails

- The backend owns catalogue values, tenant resolution, permissions, onboarding readiness, payroll, and accounting facts.
- The frontend must not infer financial figures or apply localization/presets from country or institution type.
- New API selectors must be tenant-scoped and documented in OpenAPI; frontend adapters and types must change with them.
- Unsupported exports remain labelled by the actual format. No XLSX/PDF controls will be advertised without a backend contract.
- This audit does not supersede `DEVELOPMENT_DISCREPANCIES_AND_LIMITATIONS.md`; newly durable limitations belong there with one current status per ID.
